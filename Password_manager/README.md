# Password-Manager
A lightweight, secure, and user-friendly CLI (Command Line Interface) application built with Python to safely store, manage, and retrieve your passwords locally.

--> Features
Master Password Security: Access all your credentials securely using a single master password.

Password Encryption: Uses robust cryptographic algorithms (e.g., cryptography / Fernet) to encrypt passwords before saving.

Password Generation: Built-in random password generator to create strong, unhackable passwords.

Credential Management: Easily add, view, update, and delete login details for various services.

Local Storage: Keep your sensitive data stored safely on your machine without relying on third-party cloud servers.
